# Shaurya Web & Apps — Portfolio Website

## Files
- `index.html` — website structure and content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation, scroll progress and reveal animations
- `assets/` — supplied SAO Defence Academy screenshots and brand image

## Run locally
1. Extract the ZIP file.
2. Open the `shaurya_web_apps_portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Keep the `assets` folder beside `index.html`.

## Before publishing
- Confirm you have permission to publicly show the SAO Defence Academy screenshots and project.
- Confirm the contact email is correct.
- Replace any content that you want to personalize further.
- The site is a static front-end portfolio. It does not include a database, admin panel, or backend enquiry storage.
- App development is described as a service that can be scoped separately; do not promise a mobile app delivery until the required technology and scope are agreed.

## Publishing
You can publish this static site using a static hosting provider such as GitHub Pages, Netlify, or Vercel. Configure the project folder as the site root.
